Циклы с предусловием и постусловием

Вариант 13



Описание задачи:

Программа определяет координаты стенки для заданных температур t (в градусах Цельсия) и выводит таблицу значений. Расчет выполняется в два этапа: первый участок реализован циклом с постусловием (do-while), второй участок - циклом с предусловием (while).



Порядок ввода:

Программа выводит приглашение к вводу и ожидает 6 вещественных чисел через пробел или перенос строки строго в следующем порядке:

Температуры на границах стенки: t1, t2 (в градусах Цельсия).

Толщины слоев: delta1, delta2 (в сантиметрах, в расчете переводятся в метры).

Коэффициенты теплопроводности слоев: lambda1, lambda2.



Запуск программы:

Открыть проект Lab02 в Visual Studio. Собрать решение через меню Build → Build Solution (или Ctrl+Shift+B). Запустить программу через меню Debug → Start Without Debugging (или Ctrl+F5) или с отладчиком (F5). В появившемся окне консоли ввести необходимые 6 чисел и нажать Enter для получения таблицы результатов.
